This is an exercise on SigLip2 text + EVA02 vision model supervised fine-tuning.

Collaboration is more than welcomed.

**Quick Start**

Follow `prompt_generator_gpt.py` to create a OPENAI chat completion batch job, and submit the requested prompts with the command lines shared in the script.

```
cd SigLip2-ReID/
chmod +x ./start.sh
./start.sh
```
